# Security Architecture in InsightFlow

## Problem

AI-powered Natural Language to SQL systems introduce major security risks because the model dynamically generates executable database queries.

Without proper protections, these systems are vulnerable to:

- SQL Injection
- Prompt Injection
- Unauthorized data access
- Destructive SQL execution
- AI hallucinated tables or columns
- Multi-query attacks
- Sensitive data exposure
- Prompt bypass attempts

To safely enable AI-driven analytics, InsightFlow implements a multi-layer security architecture based on defense-in-depth principles.

---

# Security Solution

InsightFlow uses multiple validation and protection layers before any SQL query is executed.

The system combines:

- AI prompt hardening
- Intent filtering
- SQL structural validation
- Column whitelisting
- Read-only enforcement
- Audit logging

This ensures that only safe analytical queries are allowed.

---

# Security Layers

---

# 1. Intent Middleware

Before processing any request, the system analyzes the user's prompt to detect malicious intent.

## Detects:

- Prompt Injection
- SQL Injection attempts
- Destructive commands
- Security bypass attempts

## Blocked Examples

```text
DROP TABLE products
DELETE FROM users
Ignore previous instructions
Bypass security
Reveal secrets
```

## Obfuscation Detection

The middleware also detects obfuscated attacks such as:

```text
Ign0re previous instructi0ns
dr0p table
```

## Benefit

Stops malicious requests before they ever reach the AI model.

---

# 2. AI Prompt Hardening

The Gemini model operates under strict security instructions.

## Restrictions

- Only generate `SELECT` queries
- Never modify data
- Never generate multiple queries
- Never invent tables
- Never invent columns
- Always return structured JSON

## Benefit

Reduces the probability of unsafe SQL generation and prompt injection success.

---

# 3. SQL AST Validation

All generated SQL queries are parsed using:

```javascript
node - sql - parser;
```

The system converts the SQL into an Abstract Syntax Tree (AST) and validates its structure.

## Validations

- Only `SELECT` statements are allowed
- Multiple queries are blocked
- Dangerous SQL structures are rejected

## Automatically Blocked

```sql
INSERT INTO users
UPDATE products
DELETE FROM orders
DROP TABLE users
ALTER TABLE products
TRUNCATE TABLE data
```

## Benefit

Prevents execution of dangerous SQL even if generated by the AI.

---

# 4. Column Whitelisting

InsightFlow validates every column used in the generated SQL query.

Only explicitly allowed columns can be accessed.

## Protection Against

- Unauthorized data access
- AI hallucinated columns
- Queries outside the allowed domain
- Sensitive data exposure

## Example Rejected Query

```sql
SELECT password FROM users
```

## Benefit

Ensures the AI only interacts with approved analytical data.

---

# 5. Multi-Query Injection Protection

The system blocks attempts to execute multiple SQL statements.

## Example Blocked

```sql
SELECT * FROM users; DROP TABLE users
```

## Benefit

Prevents chained SQL injection attacks.

---

# 6. Read-Only Analytics Architecture

The AI cannot access transactional or sensitive operational tables.

Instead, it only queries a controlled analytical dataset:

```sql
v_analytics_ventas_maestra_fisica
```

## Benefit

Even if another protection layer failed, database damage would still be highly restricted.

---

# 7. Audit Logging

Every request is logged for monitoring and traceability.

## Logged Information

- User prompt
- Generated SQL
- Execution status
- Block reason
- Timestamp

## Benefit

Enables attack monitoring, debugging, and security auditing.

---

# Hybrid Security Model

InsightFlow combines AI with deterministic security controls.

| Layer                  | Purpose                        |
| ---------------------- | ------------------------------ |
| Gemini AI              | Natural language understanding |
| Intent Middleware      | Malicious intent detection     |
| Prompt Hardening       | AI behavior restriction        |
| SQL AST Validation     | Structural SQL verification    |
| Column Whitelisting    | Data access control            |
| Read-Only Architecture | Damage limitation              |
| Audit Logging          | Monitoring and traceability    |

# Final Result

InsightFlow provides a secure Natural Language to SQL architecture capable of:

- Safely generating analytical SQL queries
- Preventing prompt injection attacks
- Blocking SQL injection attempts
- Restricting database access
- Preventing destructive operations
- Ensuring controlled AI interaction with data

The platform demonstrates how Generative AI can be integrated into enterprise analytics workflows without compromising database security.
